## 🌒 The Idea & Genesis

**Nightbuild Studio** was founded by a collective of four computer science students who grew restless watching agencies churn out identical, beige corporate templates and 40-slide sales decks that never translate into living code.

We recognized two distinct worlds that desperately needed each other:
1. **Visionary Founders & Brands** who want an undeniable, unconventional web presence with sub-second edge performance and fluid choreography.
2. **Computer Science Researchers & Students** building groundbreaking capstone engines, algorithmic tools, and distributed prototypes that deserved a user experience worthy of their code.

We established a single rule: **our portfolio is our only marketing**. Every hour of our workshop energy is poured into direct code prototyping, hardware-accelerated shaders, and shipping high-impact web artifacts that command attention on their own merits.

## 🛠️ Flagship Studio Utilities

### 1. ⚡ The Midnight Architect (`/blueprint`)
An interactive, self-serve project scoping and architecture estimation engine:
- **Archetype Selector**: Tailor estimates across commercial MVPs, CS capstones, and creative portfolios.
- **Dynamic Stack Configurator**: Toggle Supabase PostgreSQL, Gemini AI Gateways, Stripe rails, and WebSocket engines in real time.
- **Instant Live Output**: Calculates realistic sprint timelines, engineering complexity scores (1.0 to 5.0), and fixed investment brackets with zero sales pressure.
- **AI Architecture Spec Generator**: Generates exportable markdown architectural blueprints with 1 click.
- **One-Click Inquiry Handoff**: Transfers calculated scope directly to our lead intake queue.

An interactive AI assistant embedded as a floating nocturnal widget featuring the **black Batman bat insignia**:
- **Powered by Google Gemini 3.6 Flash**: Grounded with deep context on our studio ethos, projects (*Chronos*, *Vesperal*, *Aetherform*), and engineers.

## 🏛️ Core Tenets & Engineering Philosophy

- **01 / Scaffold in Code**: Figma is a compass, not the destination. Scroll physics, frame rates, and responsive text elasticity only become real once rendered in actual browser DOM.
- **02 / Sub-Second Baseline**: Visual boldness must never penalize network speed. We hand-tune asset budgets, compress shader pipelines, and leverage edge databases for instantaneous traversal.
- **03 / Complete Authorship & Repository Ownership**: No proprietary lock-in. Every client site and capstone includes 100% source code transfer, database sovereignty, and clear technical documentation.

## 💻 Developer Quickstart (For Collaborators)

```bash
# 1. Clone the repository
git clone https://github.com/SHANCHAARI/thenightbuild.git
cd thenightbuild

# 2. Install dependencies
npm install

# 3. Environment configuration
cp .env.example .env.local
# Add NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, GEMINI_API_KEY

# 4. Start nocturnal dev environment
npm run dev
# Running on http://localhost:3005
```
